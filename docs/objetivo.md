# Objetivo del proyecto

## Objetivo general

Analizar las características, distribución y comportamiento de los proyectos mineros de la provincia de Mendoza mediante técnicas de exploración, transformación y visualización de datos, y utilizar los resultados para desarrollar modelos de aprendizaje supervisado y no supervisado que permitan identificar patrones y perfiles dentro de la actividad minera.

## Preguntas iniciales

- ¿Cómo se distribuyen los proyectos mineros de Mendoza?
- ¿Qué minerales y estados aparecen con mayor frecuencia?
- ¿Qué características diferencian a los proyectos?
- ¿Qué relaciones existen entre las variables disponibles?
- ¿Qué variable numérica disponible puede utilizarse como objetivo de regresión de forma justificable?
- ¿Qué variable categórica puede utilizarse como objetivo de clasificación de forma justificable?
- ¿Podemos identificar perfiles de proyectos mediante clustering?

## Criterio

No se fijará una variable objetivo artificial antes de conocer los datasets reales. La elección de targets y variables predictoras se justificará a partir del AED, la calidad de los datos y el significado de cada variable.
